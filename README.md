# Biodata

Personal portfolio of Md. Mahrab Ferdous, a Computer Science and Engineering student at Daffodil International University.

## Contents

- About, personal information, and education
- Skills and project gallery
- Wicked Private Limited future venture plans
- Contact details and social links

## Run locally

Open `index.html` in a browser, or serve this folder with VS Code Live Server. The site uses plain HTML, CSS, and JavaScript; no build step is required.

## Customize

Edit `script.js` to update the portfolio's roles, social links, skills, project details, and venture cards. Edit `index.html` for page content and `style.css` / `glint-theme.css` for styling.
